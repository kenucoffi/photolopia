Photolopia

A full-stack photography platform that connects photographers with clients.
Photographers can showcase their work, while clients can browse photographers and contact them for photography services.

Technologies Used
Backend
Laravel
PHP
sqlite
REST API Authentication


Frontend
Next.js
Tailwind CSS
React.js

Project Overview

Photolopia is designed to help photographers promote their photography work online and help clients find professional photographers easily.

The system supports two types of users:

Clients
Photographers
User Types
1. Client

Clients can:

Create an account
Login and manage their profile
Browse photographers
Search photographers
View photographer profiles and posts

Client information includes:

Name
Email
Phone Number
Location

Client profiles are not visible publicly to other users.

2. Photographer

->Photographers can:

Register and login
Edit their profile
Upload photography work
Add descriptions to posts
Showcase photography categories such as:
Wedding
Birthday
other

->Photographer information includes:

Name
Email
Phone Number
Specialty
Bio
Location
Instagram Link


-> Main Features

1. Home Page
