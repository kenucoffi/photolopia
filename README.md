photolopia is project aim to connect photographers with clients
it have both backend and front-end
the backend is build using Laravel freamwork and the front-end is create using Next.js and Tailwind

-------- the logic of this project ----------

there are two user type client and photographer
if you signup as photographer you can post your work photos and description if you are autenticated
if you are user you can authenticat and see photographers but client are not visible to others
clients have information like
    name , email , phone , location
photographars have information like
    name ,email, phone , speciality , bio,location instagram 
    posts like birth_day ,wedding and others post

       ->home post page

             -> list of all photographers
        -> search bar
